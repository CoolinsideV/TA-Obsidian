
### 第一步：搭建基础场景

1. **创建地面**：在 Unity 的 `Hierarchy`（层级视图）空白处右键 -> `3D Object` -> `Plane`。
    
2. **创建发光目标**：再次右键 -> `3D Object` -> `Sphere`（球体），并在右侧 `Inspector` 面板将其 `Transform` 的 Position 设为 `(0, 0.5, 0)`。
    
3. **创建玩家**：右键 -> `3D Object` -> `Capsule`（胶囊体），命名为 `Player`，将其 Position 设为 `(3, 1, 0)`（确保初始状态离球体有一定距离）。
    

### 第二步：编写 HLSL 着色器代码

1. **新建 Shader 文件**：在底部的 `Project`（项目窗口）中右键 -> `Create` -> `Shader` -> `Universal Render Pipeline` -> `Unlit Shader`。
    
2. **重命名**：将新建的文件严格命名为 `ProximityGlowShader`。
    
3. **粘贴代码**：双击该文件唤起 Visual Studio 2022，全选里面的默认代码并删除，替换为以下完整代码，然后按下 `Ctrl + S` 保存：
    

High-level shader language

```
Shader "Custom/ProximityGlow"
{
    Properties
    {
        // 材质面板上暴露的基础色和发光色
        _BaseColor ("Base Color", Color) = (0.2, 0.2, 0.2, 1)
        _GlowColor ("Glow Color", Color) = (0, 1, 1, 1)
    }
    SubShader
    {
        Tags { "RenderType"="Opaque" "RenderPipeline"="UniversalPipeline" }
        
        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes 
            { 
                float4 positionOS : POSITION; 
            };
            
            struct Varyings 
            { 
                float4 positionCS : SV_POSITION; 
                float3 positionWS : TEXCOORD0; // 用于传递顶点世界坐标
            };

            // 常量缓冲区，接收来自 C# 的数据
            CBUFFER_START(UnityPerMaterial)
                half4 _BaseColor;
                half4 _GlowColor;
                float3 _PlayerPos; // 接收 C# 传来的玩家位置
                float _Radius;     // 接收 C# 传来的触发半径
            CBUFFER_END

            Varyings vert(Attributes input)
            {
                Varyings output;
                // 将顶点从对象空间转换到世界空间，并传递给片元着色器
                output.positionWS = TransformObjectToWorld(input.positionOS.xyz);
                // 将世界坐标转换到裁剪空间用于最终屏幕显示
                output.positionCS = TransformWorldToHClip(output.positionWS);
                return output;
            }

            half4 frag(Varyings input) : SV_Target
            {
                // 1. 计算当前像素的世界坐标与玩家坐标的距离
                float dist = distance(input.positionWS, _PlayerPos);
                
                // 2. 计算发光强度：距离越近，强度越接近1；超出半径则为0
                float glowIntensity = 1.0 - saturate(dist / _Radius);
                
                // 3. 使用平滑阶跃函数让渐变边缘更自然
                glowIntensity = smoothstep(0.0, 1.0, glowIntensity);
                
                // 4. 根据强度在基础色和发光色之间进行线性插值
                return lerp(_BaseColor, _GlowColor, glowIntensity);
            }
            ENDHLSL
        }
    }
}
```

### 第三步：编写 C# 控制端代码

1. **新建脚本**：在 `Project` 窗口空白处右键 -> `Create` -> `C# Script`，严格命名为 `ProximityGlowController`。
    
2. **粘贴代码**：双击打开脚本，替换为以下完整代码，保存并等待 Unity 编译图标转完：
    

C#

```
using UnityEngine;

// 强制要求挂载此脚本的游戏对象必须拥有 Renderer 组件
[RequireComponent(typeof(Renderer))]
public class ProximityGlowController : MonoBehaviour
{
    [Header("追踪目标 (通常是玩家)")]
    public Transform playerTarget;
    
    [Header("发光触发半径")]
    public float activationRadius = 3.0f;

    private Material targetMaterial;

    void Start()
    {
        // 获取当前物体上的材质实例
        // 注意：使用 .material 会实例化一个新材质，防止修改影响到其他同材质物体
        targetMaterial = GetComponent<Renderer>().material;
    }

    void Update()
    {
        // 确保目标和材质都不为空时才执行
        if (playerTarget != null && targetMaterial != null)
        {
            // 将玩家的实时世界坐标传递给 Shader 中的 "_PlayerPos" 变量
            targetMaterial.SetVector("_PlayerPos", playerTarget.position);
            
            // 将触发半径传递给 Shader 中的 "_Radius" 变量
            targetMaterial.SetFloat("_Radius", activationRadius);
        }
    }
}
```

### 第四步：材质绑定与运行测试

1. **生成材质**：在 `Project` 窗口中，右键点击写好的 `ProximityGlowShader` 文件 -> `Create` -> `Material`。这会生成一个默认绑定了该 Shader 的材质球，给它命名为 `Mat_Glow`。
    
2. **赋予模型**：将 `Mat_Glow` 材质球直接拖拽到场景中的 `Sphere`（球体）上。
    
3. **挂载逻辑**：在 `Hierarchy` 中点击选中 `Sphere`，把 `ProximityGlowController` 脚本拖拽到右侧 `Inspector` 面板的空白处完成挂载。
    
4. **设置目标**：在 `Sphere` 的 `Inspector` 面板中找到刚刚挂载的脚本组件，把 `Hierarchy` 里的 `Player` 拖拽进 `Player Target` 槽位中。
    
5. **见证效果**：点击 Unity 正上方的 `Play` 运行按钮。在 `Scene` 视图选中 `Player`，拖动它的坐标轴靠近球体，你就会看到球体随着距离的变化产生发光渐变。
    

代码跑通后，你可以尝试修改 C# 脚本面板上的 `Activation Radius` 数值，观察光圈大小的变化。在完全掌握这套传参流程后，你想不想试着在 HLSL 的顶点着色器部分加几行代码，让球体在发光的同时发生物理上的膨胀变形？
