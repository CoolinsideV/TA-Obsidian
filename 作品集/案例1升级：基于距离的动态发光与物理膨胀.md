#### 第一步：搭建基础场景

1. **创建地面**：在 `Hierarchy`（层级视图）右键 -> `3D Object` -> `Plane`。
    
2. **创建受击目标**：右键 -> `3D Object` -> `Sphere`，将其 `Transform` 的 Position 设为 `(0, 0.5, 0)`。
    
3. **创建玩家**：右键 -> `3D Object` -> `Capsule`，命名为 `Player`，将其 Position 设为 `(3, 1, 0)`。
    

#### 第二步：编写进阶版 HLSL 着色器（核心改造）

这次我们需要在 Shader 中读取顶点的**法线（Normal）**，并把距离计算的逻辑提前到顶点着色器（Vertex Shader）中完成，这样既能控制顶点位移，又能把计算好的强度传给像素着色器，节省性能开销。

1. 新建一个 Unlit Shader，命名为 `ProximityGlowAndExpand`。
    
2. 双击在 Visual Studio 2022 中打开，替换为以下完整代码，然后 `Ctrl + S` 保存：
    

High-level shader language

```
Shader "Custom/ProximityGlowAndExpand"
{
    Properties
    {
        _BaseColor ("Base Color", Color) = (0.2, 0.2, 0.2, 1)
        _GlowColor ("Glow Color", Color) = (0, 1, 1, 1)
        // 新增：在材质面板上暴露膨胀强度的控制滑块
        _ExpandAmount ("Expand Amount", Range(0, 1)) = 0.2 
    }
    SubShader
    {
        Tags { "RenderType"="Opaque" "RenderPipeline"="UniversalPipeline" }
        
        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes 
            { 
                float4 positionOS : POSITION; 
                float3 normalOS : NORMAL; // 【新增】获取模型的顶点法线方向
            };
            
            struct Varyings 
            { 
                float4 positionCS : SV_POSITION; 
                float  glowIntensity : TEXCOORD0; // 【修改】直接在顶点计算好发光强度并传递
            };

            CBUFFER_START(UnityPerMaterial)
                half4 _BaseColor;
                half4 _GlowColor;
                float _ExpandAmount; // 接收面板上的膨胀参数
                float3 _PlayerPos;   // 接收 C# 传来的玩家位置
                float _Radius;       // 接收 C# 传来的触发半径
            CBUFFER_END

            Varyings vert(Attributes input)
            {
                Varyings output;
                
                // 1. 获取顶点的初始世界坐标
                float3 originalPosWS = TransformObjectToWorld(input.positionOS.xyz);
                
                // 2. 计算当前顶点与玩家的距离
                float dist = distance(originalPosWS, _PlayerPos);
                
                // 3. 计算影响强度并平滑处理 (0到1之间)
                float intensity = 1.0 - saturate(dist / _Radius);
                intensity = smoothstep(0.0, 1.0, intensity);
                
                // 4. 【核心位移逻辑】让顶点在对象空间内，沿着法线方向向外移动
                input.positionOS.xyz += input.normalOS * intensity * _ExpandAmount;
                
                // 5. 将偏移后的新顶点坐标，转换到裁剪空间输出到屏幕
                output.positionCS = TransformObjectToHClip(input.positionOS.xyz);
                
                // 6. 将计算好的强度打包传给片元着色器
                output.glowIntensity = intensity;
                
                return output;
            }

            half4 frag(Varyings input) : SV_Target
            {
                // 片元着色器现在非常轻量，只需根据顶点传来的强度进行颜色插值
                return lerp(_BaseColor, _GlowColor, input.glowIntensity);
            }
            ENDHLSL
        }
    }
}
```

#### 第三步：编写 C# 控制端代码

这里的控制代码与之前基本一致，负责将实时的玩家坐标持续“喂”给显存。

1. 新建 C# 脚本，命名为 `ProximityGlowController`。
    
2. 替换为以下代码并等待编译：
    

C#

```
using UnityEngine;

[RequireComponent(typeof(Renderer))]
public class ProximityGlowController : MonoBehaviour
{
    [Header("追踪目标 (通常是玩家)")]
    public Transform playerTarget;
    
    [Header("触发交互的半径")]
    public float activationRadius = 3.0f;

    private Material targetMaterial;

    void Start()
    {
        targetMaterial = GetComponent<Renderer>().material;
    }

    void Update()
    {
        if (playerTarget != null && targetMaterial != null)
        {
            // 将玩家的实时世界坐标写入 Constant Buffer
            targetMaterial.SetVector("_PlayerPos", playerTarget.position);
            // 写入触发半径
            targetMaterial.SetFloat("_Radius", activationRadius);
        }
    }
}
```

#### 第四步：绑定与观察物理变形

1. **创建材质**：右键点击 `ProximityGlowAndExpand` Shader，创建材质球，并拖拽给场景中的 `Sphere`。
    
2. **调整膨胀度**：点击这个材质球，你会发现在 Inspector 面板上多了一个 `Expand Amount` 滑块。你可以把它拖到 `0.3` 左右。
    
3. **挂载逻辑**：把 `ProximityGlowController` 脚本挂给 `Sphere`，并把场景中的 `Player` 拖进脚本的 `Player Target` 槽位里。
    
4. **运行测试**：点击 `Play`，在 Scene 视图拖动 `Player` 靠近球体。这次，球体不仅会变成青蓝色，它的体积还会肉眼可见地“肿”起来！
